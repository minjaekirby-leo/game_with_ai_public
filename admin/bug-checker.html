🔍 일반적인 버그 패턴 및 해결 방법

공통 버그 패턴
1. 키보드 입력 문제:
- e.key와 e.code 모두 지원하도록 수정
- 화살표 키 + WASD 키 동시 지원
- 스페이스바는 ' '와 'Space' 모두 체크

2. 충돌 감지 문제:
- 거리 기반 충돌 → 박스 충돌로 변경
- 충돌 박스 크기 조정
- 무적 시간 추가로 연속 충돌 방지

3. 게임 오버 후 재시작 문제:
- 모든 게임 변수 초기화
- 타이머 및 인터벌 정리
- 이벤트 리스너 중복 방지

4. 모바일 터치 지원:
- 터치 이벤트 추가
- 가상 조이스틱 구현
- 화면 크기 반응형 처리

5. 성능 최적화:
- requestAnimationFrame 사용
- 불필요한 객체 제거
- 캔버스 최적화
